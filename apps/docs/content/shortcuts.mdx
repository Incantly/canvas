# Keyboard shortcuts

## Tools

| Key | Tool |
| --- | --- |
| `V` or `1` | Select |
| `H` | Hand (or hold `Space`) |
| `D`, `P`, or `B` | Draw |
| `I` | Highlight |
| `E` | Eraser |
| `K` | Laser pointer |
| `A` | Arrow |
| `L` | Line |
| `G` | Shape (current kind) |
| `R` | Rectangle |
| `O` | Ellipse |
| `T` | Text |
| `N` | Sticky note |

## Editing

| Key | Action |
| --- | --- |
| `⌘Z` / `⇧⌘Z` | Undo / redo |
| `⌘A` | Select all |
| `⌘C` / `⌘X` / `⌘V` | Copy / cut / paste |
| `⌘D` | Duplicate |
| `⌫` | Delete selection |
| `⇧⌘⌫` | Clear the board (undoable) |
| `Enter` | Edit the selected shape's text |
| `Esc` | Done editing / clear selection |

## Arranging

| Key | Action |
| --- | --- |
| `]` | Bring to front |
| `[` | Send to back |
| Arrow keys | Nudge selection |
| `Shift` + arrows | Nudge farther |

## Camera

| Key | Action |
| --- | --- |
| `⇧1` | Zoom to fit |
| `⇧0` | Reset zoom to 100% |
| `⌘+` / `⌘−` | Zoom in / out |
| Scroll | Pan (trackpad) / zoom (`⌘` + wheel) |
| Pinch | Zoom |

On Windows and Linux, `⌘` is `Ctrl`.
