# Getting started

Incantly Canvas is an MIT-licensed infinite-canvas whiteboard SDK. One engine,
three packages:

| Package | For |
| --- | --- |
| [`@incantly/canvas-react`](https://www.npmjs.com/package/@incantly/canvas-react) | React apps — a `<Canvas />` component |
| [`@incantly/canvas-react-native`](https://www.npmjs.com/package/@incantly/canvas-react-native) | React Native / Expo — a WebView component with a typed bridge |
| [`@incantly/canvas`](https://www.npmjs.com/package/@incantly/canvas) | Any web page — framework-free, zero dependencies |

Every board comes complete: pressure ink, highlighter, shapes with editable
labels, arrows, lines, text, sticky notes, images, laser pointer, selection,
infinite pan/zoom, per-gesture undo, light and dark themes, grids, and PNG
export.

## Install

```sh
npm install @incantly/canvas-react
```

For plain JS use `@incantly/canvas`; for React Native use
`@incantly/canvas-react-native react-native-webview`.

## First board

```jsx
import { Canvas } from '@incantly/canvas-react'
import '@incantly/canvas/canvas.css'

export default function App() {
  return (
    <div style={{ position: 'fixed', inset: 0 }}>
      <Canvas theme="light" grid="dots" />
    </div>
  )
}
```

The component fills its container, so the container needs real dimensions —
`position: fixed; inset: 0` for a full-page board, or any sized `div` for an
inline one.

That's a working whiteboard. Draw with the pen, add shapes and sticky notes,
switch the theme from the board's ⋮ menu.

## The 60-second tour

Everything revolves around two objects:

- **`editor`** — tools, camera, selection, theme:
  `editor.setTool('draw')`, `editor.fitContent()`, `editor.setTheme('dark')`.
- **`editor.store`** — the document: `store.getSnapshot()` returns plain
  JSON, `store.listen((diff) => ...)` fires on every change, and
  `store.undo()` / `store.redo()` walk history.

In React you reach them through a ref (`ref.current.editor`); in plain JS,
`createCanvas()` returns them directly.

```jsx
const ref = useRef(null)

<Canvas
  ref={ref}
  snapshot={saved}                          // restore a saved board
  autoFit                                   // fit content on mount/resize
  onChange={(diff, source, editor) =>       // every document change
    save(editor.store.getSnapshot())}
/>
```
