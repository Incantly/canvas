# Incantly document web playground

Run from the repository root:

```sh
npm run dev:document
```

The Milestone 11.2 screen exercises the continuous writing surface, document-only
light and dark themes, responsive spacing, read-only mode, transient placeholders,
cross-paragraph selection, accessible formatting toolbars, selection formatting,
slash commands, and canonical JSON updates. It requires no account,
collaboration provider, backend, or network connection after dependencies are installed.
